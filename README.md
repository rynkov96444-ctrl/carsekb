# CarsEkb — Автомобильный портал Екатеринбурга

Автомобильный портал, объединяющий сервисы, контент и сообщество автолюбителей Екатеринбурга.

## Возможности

- **Каталог сервисов** — детейлинг центры, малярные станции, СТО с рейтингами и отзывами
- **Привоз авто** — калькулятор стоимости, трекер заказа, проверенные брокеры
- **Car Spotting** — галерея уникальных автомобилей на дорогах города
- **Блог** — полезные статьи, гайды, новости
- **Админка** — управление контентом, модерация сервисов и отзывов

## Стек технологий

- **Framework:** Next.js 14 (App Router)
- **Database:** PostgreSQL + Prisma ORM
- **Authentication:** NextAuth.js
- **Styling:** Tailwind CSS + shadcn/ui
- **Icons:** Lucide React
- **Maps:** 2GIS API (планируется)

## Установка и запуск

### 1. Установите зависимости

```bash
npm install
```

### 2. Настройте базу данных

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Заполните переменные окружения:
- `DATABASE_URL` — строка подключения к PostgreSQL
- `NEXTAUTH_SECRET` — секретный ключ для NextAuth (можно сгенерировать через `openssl rand -base64 32`)

### 3. Инициализируйте базу данных

```bash
# Создать таблицы в БД
npm run db:push

# Сгенерировать Prisma Client
npm run db:generate
```

### 4. Запустите проект

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Скрипты

- `npm run dev` — запуск dev-сервера
- `npm run build` — сборка production-версии
- `npm run start` — запуск production-сервера
- `npm run lint` — проверка кода
- `npm run db:generate` — генерация Prisma Client
- `npm run db:push` — синхронизация схемы с БД
- `npm run db:studio` — открытие Prisma Studio

## База данных

Основные модели:
- **User** — пользователи (обычные, модераторы, админы)
- **Service** — автосервисы с категориями, рейтингами, отзывами
- **Review** — отзывы на сервисы
- **Post** — статьи блога
- **SpottingPost** — посты car spotting
